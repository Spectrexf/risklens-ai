# RiskLens AI

AI-powered financial risk analysis platform built as a full-stack SaaS application.

![Node.js](https://img.shields.io/badge/Node.js-v22-green) ![Express](https://img.shields.io/badge/Express-v5-black) ![MongoDB](https://img.shields.io/badge/MongoDB-Mongoose-green) ![Groq](https://img.shields.io/badge/AI-Groq-orange) ![Stripe](https://img.shields.io/badge/Payments-Stripe-blue)

## What is RiskLens AI?

RiskLens AI is a full-stack SaaS platform that provides institutional-grade financial risk analysis powered by artificial intelligence. It combines real market data from Yahoo Finance with quantitative models (Sharpe, Beta, VaR, Monte Carlo) and AI-generated reports via Groq to deliver professional investment analysis accessible to everyone.

## Features

### Manual Analysis
- Input 7 financial metrics for any company (listed or unlisted)
- Calculates 6 financial ratios: liquidity, debt/equity, ROE, net margin, ROA, risk score 0-100
- AI-generated professional report in 5 structured sections

### Advanced Automatic Analysis
- Search any listed company by name — real data from Yahoo Finance
- Quantitative metrics: Sharpe Ratio, Sortino Ratio, Beta, Alpha, CAPM
- Maximum Drawdown, VaR 95%/99%
- Monte Carlo simulation with 10,000 trajectories (Box-Muller method)
- Wyckoff technical analysis (5 phases)
- Goldman Sachs-level research report generated by Groq AI (llama-3.3-70b)

### Portfolio Optimization
- Select multiple companies from your history
- Stochastic binomial model + Markov chains
- 10,000 simulations x 12 months per company
- 8,000 random weight combinations to maximize Sharpe Ratio
- AI-generated portfolio explanation

### Professional PDF Export
- Dark header with colored risk badge
- 3-column ratio grid
- Markdown parser for AI report sections
- Professional disclaimer footer

### Financial News
- 4 RSS feeds: Nasdaq, ForexLive, CoinDesk, Yahoo Finance
- Impact classification (high/medium/low)
- Category filters

### Forex Correlations
- 8 currency pairs interactive heatmap
- 5 timeframes (1D, 1W, 1M, 3M, 1Y)

### Stripe Subscriptions
- Free plan: 5 analyses total
- Premium plan: 29/month, unlimited
- Verified webhook with HMAC signature

### Security
- JWT authentication (7-day expiry)
- bcrypt password hashing (cost factor 10)
- Rate limiting: 3 levels (login, analysis, general)
- Role-based access control (user/admin)
- Password recovery via email (Resend API, 15-min token)
- Multer file validation (type + 5MB limit)

## Architecture

6-layer MVC pattern adapted for REST API:
- **Routes** — define endpoints and connect to controllers
- **Middleware** — JWT auth, rate limiting, file upload validation
- **Controllers** — business logic and request/response handling
- **Services** — external integrations (Groq, Yahoo Finance, Stripe, Email, PDF)
- **Models** — MongoDB schemas (User, Analysis, Post, Suggestion, ResetToken)
